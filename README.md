# BEAN BLITZ · 豆豆冲冲冲

糖果色 3D 派对闯关游戏，包含 12 种随机关卡、24 位选手、背景音乐和本地双人分屏。

## 在线游玩

[打开游戏](https://ericcui-debug.github.io/bean-blitz/)

每次重开会随机生成新路线；大厅也可以换一条赛道。前 12 名晋级，每局最长 300 秒。

## 操作

- 单人：WASD / 方向键移动，空格跳跃，Shift 飞扑。
- 双人 P1（上屏）：WASD 移动，空格跳跃，左 Shift 飞扑。
- 双人 P2（下屏）：方向键移动，右 Shift 跳跃，/ 飞扑。
- Esc 暂停，F 全屏；右上角可以分别关闭音乐和音效。

双人模式在同一台电脑上共用键盘，其他选手为本地 AI。手机支持单人触控游玩：左侧虚拟摇杆移动，右侧跳跃和飞扑，按住跳跃可连续跳。

## 离线游玩

下载 site/index.html，使用浏览器打开。画面、字体和音乐均可离线使用。

## 发布
